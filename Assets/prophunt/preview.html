PropHunt phone app - browser preview

Runs the shipped app.js and app.css against a stand-in mod, so structure, copy, state and flow can be checked without launching the game. Close, not identical: Chrome has real CSS and the game has a renderer that implements a subset of it, the body text is the game's own Open Sans but measured by a browser rather than by TextMeshPro, and the clock is a stand-in seven-segment face because the game's own is a TMP asset, not a font file. Judge structure, copy, state and flow here; judge the layout itself in game with F9 and Ctrl+F10.

733 x 400 css, drawn at 1.64x - the density the game uses
